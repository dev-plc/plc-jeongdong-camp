## 참고

- `poster-02-tamheom.png` 의 회비 표기(취준생·학생 20,000원 / 성인 30,000원)와
  기획안 PDF의 표기(1인 20,000원)가 다릅니다. **홍보물 기준(2단가)이 최신**으로 보이며,
  `Participants.구분` 컬럼이 이 2단가를 전제로 설계되어 있습니다. 확정되면 기획안을 갱신해 주세요.
- 포스터의 `PLI` 표기는 `PLC` 로 수정 대상입니다 (D-001).
