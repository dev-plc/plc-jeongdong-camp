# 브랜드 가이드

원본 브랜드 시안(포스터·가이드·홍보물 3종)에서 뽑아낸 토큰입니다.
앱의 `docs/assets/css/app.css` 상단 `:root` 변수가 이 표를 그대로 따릅니다.

> **표기 주의**: 초기 시안에는 `PLI` 로 적혀 있으나 컨셉이 **PLC** 로 수정되었습니다(D-001).
> 앱과 신규 산출물에는 반드시 `PLC` 를 씁니다.

## 컬러

| 이름 | HEX | 쓰임 | CSS 변수 |
|---|---|---|---|
| 붉은벽돌 | `#984534` | 주색. 앱바, 주요 버튼, 강조 | `--brick` |
| 붉은벽돌(진) | `#7a3729` | 눌림 상태 | `--brick-dark` |
| 붉은벽돌(연) | `#b9705f` | 보조 강조 | `--brick-light` |
| 회색담벼락 | `#c2c2c2` | 보조색. 구분선, 비활성 | `--wall` |
| 종이 | `#f6f2ed` | 배경 | `--paper` |
| 카드 | `#fffdfa` | 카드 표면 | `--paper-2` |
| 먹 | `#2c2320` | 본문 텍스트 | `--ink` |
| 먹(연) | `#6b5d57` | 보조 텍스트 | `--ink-2` |

**의미** — 붉은벽돌은 정동의 근대 건축과 붉은 담벼락이 품은 온기, 그리고 선교사와 신앙인들의 헌신을
가리킵니다. 회색담벼락은 덕수궁 돌담과 화강암 기단처럼 묵묵히 자리를 지켜 온 세월의 흔적입니다.

## 타이포그래피

- **원본 시안 제목 서체**: 나눔에코 (네이버 배포). 웹폰트로 자유 배포되지 않아 앱에서는 쓰지 않습니다.
- **앱 대체 조합**
  - 제목 · 지점명: `Gowun Batang` (Google Fonts) — 나눔에코의 필기 느낌 대신, 정동의 고전적 인상을 살리는 명조 계열.
  - 본문 · UI: `Noto Sans KR` (Google Fonts).
- 인쇄물(포스터·현수막)은 계속 나눔에코를 쓰고, 웹만 위 조합을 씁니다.

## 그래픽 엘리먼트

시안의 4개 건물 일러스트가 답사 4개 지점과 1:1 대응합니다.

| 지점코드 | 지점명 | 일러스트 |
|---|---|---|
| `CP1` | 배재학당역사박물관 | 배재학당 건물 |
| `CP2` | 러시아 공사관과 킹스로드 | 러시아공사관 탑 |
| `CP3` | 보구여관 터 | 보구여관 한옥 |
| `CP4` | 이화여고 박물관 | 이화여고박물관(심슨기념관) |

앱에서는 각 지점의 `Checkpoints.사진URL` 에 이미지 주소를 넣으면 카드 썸네일로 쓰입니다.
디자이너에게서 개별 PNG/SVG를 받으면 `docs/assets/img/cp/` 에 `cp1.svg` … `cp4.svg` 로 넣고
시트에 `./assets/img/cp/cp1.svg` 같은 상대경로를 적으면 됩니다.
