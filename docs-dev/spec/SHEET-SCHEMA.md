# 시트 스키마 (확정본 v2)

스프레드시트 1개 안의 **탭(시트) 10개**로 구성합니다. 실제 생성은 손으로 하지 말고
`gas/Setup.gs` 의 `setupSpreadsheet()` 를 한 번 실행하면 헤더·서식·데이터 검증·시드까지 만들어집니다.

> **v2 변경점** — 행정팀 마스터시트 초안을 반영했습니다.
> `캠프 대상`(청년부/장년부)과 `참여 일자`(10/24·10/31)는 **서로 독립적**입니다.
> 청년부인데 10/31에 참여하는 인원이 실제로 있어, 이 둘을 한 컬럼으로 합치면 안 됩니다.
> 앱의 모든 "회차" 구분은 **참여 일자**를 기준으로 합니다(타임라인, 갤러리 공개 범위, 조 구분).

## 공통 규칙

- **1행이 헤더**이고, 코드는 **헤더 텍스트로 컬럼을 찾습니다**. 열 순서를 바꿔도 동작합니다.
  단, **헤더 이름을 바꾸면 깨집니다.** 이름 변경이 필요하면 `gas/Sheets.gs` 의 `COL` / `SCHEMA` 를 같이 고치세요.
- 행정가가 열을 **추가**하는 것은 자유입니다(코드가 무시합니다). 삭제만 하지 마세요.
- ID 컬럼은 코드가 생성합니다. 손으로 채우지 마세요.
- 날짜/시각 기록은 `Asia/Seoul` 기준 ISO 문자열(`2026-10-24T14:05:00+09:00`)로 저장됩니다.
- **조를 특정하는 키는 `(참여 일자, 조 배정)` 조합**입니다. 10/24의 "1조"와 10/31의 "1조"는 다른 조입니다.

## 1. `마스터` — 참가자 명단 (원장)

행정팀이 쓰는 원장 탭입니다. 헤더를 **글자까지 동일하게** 맞췄으므로 붙여넣기만 하면 됩니다.
`참가자ID` 와 `등록일시` 두 열만 코드가 추가로 씁니다.

> **탭 이름**: 코드는 `마스터` → `Participants` → `명단` 순으로 먼저 존재하는 탭을 원장으로 씁니다
> (`gas/Sheets.gs` 의 `SHEET_ALIASES`). 이미 `마스터` 탭이 있으면 `setupSpreadsheet()` 이
> `Participants` 를 새로 만들지 않고 그 탭에 필요한 헤더만 덧붙입니다.

| 헤더 | 예시 | 필수 | 설명 |
|---|---|:--:|---|
| `참가자ID` | `P0001` | 자동 | 메뉴 → "참가자ID 채우기" 로 생성 |
| `캠프 대상` | `청년부` | ● | `청년부` / `장년부` — 소속 부서 |
| `참여 일자` | `10/24(토)` | ● | `Config.SESSION_1` / `SESSION_2` 값과 **글자까지 같아야** 합니다 |
| `이름` | `이승천7377` | ● | 뒤에 붙은 4자리는 동명이인 구분용 (아래 참고) |
| `성별` | `남` | | |
| `나이` | `34` | | |
| `연락처` | `010-1234-5678` | ● | 로그인 2차 키(뒷 4자리만 비교). **API 응답에 절대 안 나감** |
| `회비 대상(2만/3만)` | `30000` | | 행정가 관리용. 참가자 화면에 미노출 |
| `입금 여부` | `완납` | | `미납` / `완납` / `면제` |
| `조 배정` | `1조` | ● | 참여 일자와 묶여 조를 특정합니다 |
| `역할` | `일반` | ● | `일반` / `조장` / `스태프` / `사역자` |
| `여행자 보험 가입` | `가입완료` | | `가입완료` / `미가입` |
| `배정 코스` | `A코스(배재 시작)` | ● | `Courses` 시트의 `코스명` 과 일치해야 합니다 |
| `비고` | | | 알레르기·이동 편의 등 |
| `등록일시` | | 자동 | |

### 이름 뒤 4자리 표기

마스터시트는 동명이인을 구분하려고 이름 뒤에 숫자 4자리를 붙여 씁니다(`이승천7377`).
참가자에게 "이승천7377"을 입력하라고 할 수는 없으므로, 서버는 다음을 모두 허용합니다.

- **이름**: `이승천` (구분번호 뗀 것) 또는 `이승천7377` (그대로)
- **뒷 4자리**: `연락처`의 마지막 4자리 **또는** 이름 뒤에 붙은 4자리

연락처가 아직 임시값(`010-1234-5678`)인 행도 이름 뒤 4자리로 로그인됩니다.
화면에 보이는 이름에서는 구분번호가 자동으로 제거됩니다.

### 로그인이 안 되는 경우

`checkDuplicates()`(메뉴 → 명단 점검)가 미리 잡아 줍니다.

- `참여 일자` 가 비어 있음 → 로그인 시 "참여 일자가 아직 배정되지 않았습니다" 안내
- `이름(구분번호 뗀 것) + 뒷4자리` 가 겹치는 사람이 둘 이상 → 참여 일자로 좁혀지지 않으면 `AMBIGUOUS`
- `참가자ID` 가 비어 있음 → "참가자ID 채우기" 실행 필요

## 2. `Teams` — 조 메타 (선택)

조 편성 자체는 `Participants.조 배정` 이 원본입니다. 이 시트는 **표시용 부가 정보**만 담습니다.
비워 둬도 앱은 정상 동작합니다(조 이름은 `1조` 처럼 그대로 표시됨).
메뉴 → "조 목록 동기화" 를 실행하면 명단에 있는 조가 자동으로 채워집니다.

| 헤더 | 예시 | 설명 |
|---|---|---|
| `참여 일자` | `10/24(토)` | `조 배정` 과 함께 조를 특정 |
| `조 배정` | `1조` | |
| `조이름` | `1조 배재` | 화면 표시명. 비우면 `조 배정` 값을 씀 |
| `색상` | `#984534` | 카드 좌측 띠 색 |
| `집결장소` | `PL교회 본당 앞` | |
| `비고` | | |

> 조장은 `Teams` 가 아니라 `Participants.역할 = 조장` 으로 판정합니다.
> `스태프` / `사역자` 도 조장과 같은 기록 권한을 갖습니다(현장에서 대신 기록해야 할 때가 있어서).

## 3. `Courses` — 배정 코스

조마다 시작 지점을 달리해 현장 혼잡을 분산합니다(기획안 리스크 대응).

| 코스명 | 방문 순서 |
|---|---|
| `A코스(배재 시작)` | `CP1,CP2,CP3,CP4` |
| `B코스(러시아 시작)` | `CP2,CP3,CP4,CP1` |
| `C코스(보구여관 시작)` | `CP3,CP4,CP1,CP2` |
| `D코스(이화여고 시작)` | `CP4,CP1,CP2,CP3` |

`Participants.배정 코스` 와 `코스명` 이 정확히 같으면 매칭되고,
다르더라도 **앞글자(A/B/C/D)** 가 같으면 매칭됩니다. 둘 다 실패하면 `Checkpoints.기본순번` 순서로 되돌아갑니다.

## 행정팀 탭 동기화 (`MasterSync.gs`)

행정팀이 쓰던 탭 간 동기화 스크립트를 같은 프로젝트에 넣었습니다. 동작은 그대로입니다.

- 다른 탭에서 `이름` 을 입력하면 `마스터` 의 해당 행을 끌어와 채웁니다.
- 어떤 탭에서 값을 고치면 같은 `이름` 을 가진 다른 탭의 같은 헤더 칸도 따라 바뀝니다.
- `성별` · `나이` · `연락처` 는 탭마다 따로 관리하므로 동기화하지 않습니다.
- 메뉴 `🔄 동기화 관리 → 헤더 일치 여부 검사` 로 마스터에 없는 헤더를 빨갛게 표시합니다.

앱과 한 프로젝트에서 돌리려고 세 가지를 조정했습니다.

| 문제 | 조정 |
|---|---|
| `onOpen` 이 두 파일에 있으면 **하나만 살아남아** 다른 메뉴가 조용히 사라짐 | `onOpen` 은 `Setup.gs` 한 곳에만 두고, 동기화 메뉴는 `addMasterSyncMenu_()` 로 붙임 |
| 헤더 검증이 앱 시트(`Config`·`Journal`·`Progress`…)를 전부 빨갛게 칠함 | 앱이 관리하는 탭은 동기화·검증 대상에서 제외 |
| 원장 탭 이름이 `마스터` 인데 앱은 `Participants` 를 찾음 | `resolveSheetName_()` 로 양쪽 모두 같은 탭을 가리키게 함 |

> `onEdit` 같은 단순 트리거는 **사람이 시트를 편집할 때만** 실행됩니다.
> 앱(웹앱)이 시트에 쓰는 값에는 반응하지 않으므로 동기화 무한루프는 생기지 않습니다.

## 초기 세팅 순서

1. Google Sheets 새 문서 생성 → 확장 프로그램 → Apps Script.
2. `gas/` 의 파일들을 붙여넣고 저장.
3. 편집기에서 `setupSpreadsheet()` 실행 → 10개 탭 + 헤더 + 시드 데이터 생성.
4. 프로젝트 설정 → 스크립트 속성에 `ADMIN_PIN`(6자리 이상) 추가.
   - `TOKEN_SECRET` 은 없으면 자동 생성됩니다.
5. `Config` 의 `DRIVE_FOLDER_ID` 와 `SESSION_1` / `SESSION_2` 확인.
6. **행정팀 명단을 `마스터` 탭에 붙여넣기** — 헤더가 같으므로 값만 그대로 붙이면 됩니다.
   (템플릿: `docs-dev/spec/participants-template.csv`)
7. 스프레드시트 메뉴 `🧭 정동캠프` 에서 차례로 실행
   - **참가자ID 채우기**
   - **조 목록 동기화**
   - **명단 점검** → 나온 경고를 모두 해소
8. 배포 → 새 배포 → 웹 앱 / 실행 계정 `나` / 액세스 `모든 사용자` → `/exec` URL 복사.
9. `docs/assets/js/config.js` 의 `API_BASE` 에 붙여넣고 push.
