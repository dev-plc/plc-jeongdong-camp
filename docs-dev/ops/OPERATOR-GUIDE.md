# 운영자 한 장 가이드 — 언제, 무엇을, 어디서

캠프 담당자가 바뀌어도 이 한 장으로 돌 수 있게 적었습니다. 설치·배포 같은 기술 절차는
[`DEPLOY.md`](DEPLOY.md), 왜 그렇게 만들었는지는 [`../spec/DECISIONS.md`](../spec/DECISIONS.md) 에 있습니다.

**도구는 넷입니다.**

| 도구 | 누가 | 무엇을 |
|---|---|---|
| 📄 **시트 탭** (구글 스프레드시트) | 행정가·PM | 명단(`마스터`), 지점·코스·일정, 설정(`Config`) |
| 🧭 **시트 메뉴** `🧭 캠프 앱` | PM | 세팅·점검·회차·동기화처럼 **여러 탭을 한꺼번에** 고치는 일 |
| 🖥 **운영 콘솔** (`admin.html`, PIN) | 운영진 | 일지 검수 · 공지 · 진행 현황·정정 · 🏆 시상 · 회비 · 설정 |
| 📱 **앱** (`index.html`) | 참가자·캠티·스태프·교역자 | 이름 + 연락처 뒷 4자리로 로그인 |

**누가 앱에서 무엇을 보나**

| 역할 (`마스터.역할`) | 조 | 앱 코스 탭 | 할 수 있는 것 |
|---|---|---|---|
| 일반 | 있음 | 코스 | 우리 조 코스·일정·공지 보기, 일지 쓰기 |
| 조장(캠티) | 있음 | 코스 | + 도착했어요 / 완료했어요, 퀴즈 점수, 조원·회비 |
| 스태프 + `담당 지점` | 비움 | **내 지점** | 그 지점에 오는 모든 조: 도착 확인·완료·퀴즈 점수 (**스태프 점수가 우선**) |
| 스태프 (담당 지점 없음) | 비움 | **진행** | 전체 조 진행 읽기 |
| 교역자 | 비움 | **진행** | 전체 조 진행 읽기 — 정정·검수는 운영 콘솔(PIN) |

교역자·스태프는 `참여 일자` 를 **비우면 전 회차**입니다(한 사람 한 행).

## 시간표

### D-30 — 틀 잡기 (PM)

| 할 일 | 어디서 |
|---|---|
| 캠프 이름·부제·로그인 부제·부서: `CAMP_NAME` `CAMP_SUBTITLE` `CAMP_TAGLINE` `AUDIENCES` | 📄 `Config` |
| 회차 이름·날짜 (예: `10/31(토)`, `2026-10-31`) | 🧭 **일정 변경 (회차 날짜)** |
| 지점(주소·위경도·미션·퀴즈 링크) · 코스(방문 순서) · 당일 일정 | 📄 `Checkpoints` · `Courses` · `Timeline` |

### D-14 — 사람 넣기 (행정가)

| 할 일 | 어디서 |
|---|---|
| 신청 설문 → `마스터` 로 (행정팀 동기화 메뉴) | 🧭 `🔄 동기화 관리` |
| 조 편성: `조 배정` · `배정 코스` · 캠티는 `역할=조장` | 📄 `마스터` |
| 스태프·교역자 행: `조 배정` 비움, 거점 스태프만 `담당 지점` (`CP1`~) | 📄 `마스터` |
| **참가자ID 채우기 → 조 목록 동기화 → 명단 점검** (이 순서) | 🧭 |

명단 점검에서 ❌ 가 **0건**이 될 때까지 고칩니다.

### D-7 — 리허설 (사전답사)

| 할 일 | 어디서 |

## 다음 캠프

같은 스프레드시트·같은 앱 주소로 합니다. PIN·Supabase 설정도 그대로입니다.

1. 🧭 **새 캠프 시작 (보관 후 비우기)** — 확인 문구 `새 캠프` 입력.
   - 스프레드시트 **통째로 보관 사본**을 같은 폴더에 만든 **뒤에만** 지웁니다(사본 실패 → 아무것도 안 지움).
   - 비우는 탭: `Progress` · `Journal` · `Notices` · `Log` · `Teams`. 로그인은 모두 끊깁니다.
   - **그대로 두는 것**: 명단(`마스터`) · `Config` · 지점·코스·일정.
2. 🔴 보관 사본의 **공유 범위**를 확인합니다 — 명단(개인정보)이 들어 있습니다.
3. 행정팀이 `마스터` 를 새 캠프 명단으로 정리합니다(설문지·동기화).
4. 그다음은 위 **D-30** 부터 다시. (선택) 사진 폴더를 새로 만들어 `DRIVE_FOLDER_ID` 교체.
5. 로고·색은 코드에 있습니다(`docs/assets/img`, `app.css` 의 `--brick`). 바꿀 때는 개발 담당에게.
